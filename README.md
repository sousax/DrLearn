# DrLearn

Landing page de uma plataforma fictícia de cursos de programação, feita só com HTML e CSS.

Online: https://sousax.github.io/DrLearn/

## O que tem

- Cabeçalho com navegação (Home, Videos, Favorite Subjects, About Us) e botão Register
- Seção principal "Dr Learn World Programming Training Center!" com chamadas para tutoriais e versão Pro
- Cards de cursos com preço e botão de compra (React JS, JavaScript, Tailwind CSS)
- Rodapé com menu de ícones

Os links e botões são apenas visuais, sem funcionalidade. O layout não é responsivo.

## Tecnologias

- HTML5
- CSS3
- Google Fonts (Poppins e Rubik)

## Como rodar

Clone o repositório e abra `index.html` no navegador.
